# Contributing

Thank you for contributing! Please follow these simple guidelines:

- Commit messages: Use conventional commits (e.g. `feat:`, `fix:`, `chore:`, `docs:`).
- Keep changes small and focused; prefer multiple commits for distinct ideas.
- Run the project's syntax checks before committing: `npm run check:syntax`.
- For larger changes, open an issue first to discuss implementation details.

Be respectful and help reviewers reproduce any issues.
